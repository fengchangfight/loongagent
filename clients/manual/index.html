loongagent 快速上手 本地版

loongagent 是一个装在你自己机器上的编码 agent：单个二进制，模型、记忆、会话全部留在本机。 这份手册只教四件事：装好、加模型、切模型、给项目配 skills。五分钟后你就能用起来。

1. 安装：把 loongagent 放进 PATH

你会得到一个二进制文件（Linux/macOS 是 loongagent，Windows 是 loongagent.exe）。它不需要安装器，放进一个目录、让这个目录进 PATH 即可。

Linux / macOS：

mkdir -p ~/.local/bin
cp loongagent ~/.local/bin/
chmod +x ~/.local/bin/loongagent

# 让 ~/.local/bin 进 PATH（bash 用户；zsh 改成 ~/.zshrc）
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

loongagent --version   # 能打印版本号就装好了

Windows（PowerShell）：

# 1. 建一个目录，把 loongagent.exe 放进去，例如：
#    C:\tools\loongagent\loongagent.exe
# 2. 把这个目录加进用户 PATH：
setx PATH "%PATH%;C:\tools\loongagent"
# 3. 关掉重开一个 PowerShell 窗口，然后：
loongagent --version
装好后，在你的项目目录里直接敲 loongagent 就进入交互界面（TUI）。 第一次启动且没配过任何模型时，会自动弹出配置向导，跟着走即可。

2. 添加模型

模型可以是云端 API（你自己的 key），也可以是本机 ollama。用向导添加最省事：

loongagent local add            # 列出服务商（本机 ollama 排第一），粘 key，现场探测
loongagent local add ollama     # 直接指定某一个服务商
loongagent local                # 查看已配置的模型和槽位顺序
loongagent local ping           # 每个模型真打一次，确认能通
向导会现场探测：能列出模型的就列出来给你选，key 不对会直接告诉你。 密钥按约定名（如 LOONG_DEEPSEEK_KEY）从 ~/.loongagent/env 或环境变量读取， 永远不会写进配置文件。

本机 ollama（不花钱、数据不出机器）：

ollama pull qwen2.5:7b-instruct     # 先拉一个模型
loongagent local add ollama         # 再把它加进来

配好的模型存在 ~/.loongagent/local.toml，顺序就是状态栏上的槽位号， 第一个是启动默认模型：

mode = "local"

[[models]]
name = "qwen2.5:7b-instruct"
provider = "ollama/qwen2.5:7b-instruct"   # 槽位 1：本机 ollama

[[models]]
name = "deepseek-flash"
provider = "deepseek/deepseek-flash"      # 槽位 2：云端

删除模型也只需要一条命令——可以按状态栏序号、名字或服务商来指定：

loongagent local                    # 先看一眼序号和名字
loongagent local delete 2           # 按序号删（删 2 号槽位）
loongagent local delete deepseek-flash   # 按名字删
loongagent local delete ollama      # 按服务商删（删掉这家配的全部）
删错了也不要紧：配置只是 ~/.loongagent/local.toml 里的几行文字， 再用 loongagent local add 加回来即可。密钥不在配置文件里，删除不会动你的 key。

3. 快捷键切换模型

会话中随时换模型，不用重启：

按键 / 命令作用
alt+1 … alt+9 直接跳到第 N 个槽位（最常用）
/1 … /9 同上；给会吞掉 Alt 的终端（tmux、部分 Windows 终端）兜底
ctrl+n / ctrl+p 下一个 / 上一个模型，循环
alt+r 或 /r 用当前选中的模型重发上一条 prompt
想让某个模型变成以后每次启动的默认模型？把它排到槽位 1： 按 ctrl+← / ctrl+→ 调整顺序（local 模式直接写回配置文件）， 或者干脆编辑 ~/.loongagent/local.toml 调整 [[models]] 顺序。

4. 配置项目级 skills

skill 就是一个 Markdown 文件，教 agent 一套工作流程（比如"本仓库提交前必跑哪些检查"）。 在会话里输入 /名字 就能调用。把它们放进项目目录，整个团队共用：

你的项目/
├── .agents/
│   └── skills/
│       └── review/            ← 一个 skill 一个目录
│           └── SKILL.md       ← 文件正文就是这个 skill 的说明书
└── .loongagent/
    └── commands/
        └── deploy.md          ← 单个命令也可以这样放

一个最小的 SKILL.md 长这样：

---
name: review
description: 提交前自查：编译、测试、检查未提交文件
---

依次执行：
1. cargo build --release，有错就修
2. cargo test，全绿才算过
3. git status，列出还没提交的文件给我确认

然后在项目里启动 loongagent，输入 /review 就会按这套流程走。 按 /help 可以看到当前会话里所有可用的 skill 和命令。

想直接用别人写好的 skills？一条命令装插件： loongagent plugin add superpowers（默认装到用户级，加 --project 装到本项目）， loongagent plugin list 查看已装插件。

5. （可选）开启语义记忆模式

loongagent 默认把会话原样记下来（record 模式，不花任何模型调用）。 语义（semantic）模式在此之上，用本机 ollama 里的一个小模型， 趁你不在打字的空闲时间把旧对话归纳成摘要。它记得的是"当时为什么这么改"， 长会话、跨天接着干活时差别最明显。不开也完全能用。

前置条件只有一个：装好 ollama 并拉一个摘要模型（摘要模型就是普通模型，小一点就够）：

ollama pull qwen2.5:7b-instruct     # 默认摘要模型；0.6B/3B 也能跑，质量打折

然后一条命令开、一条命令关：

loongagent local semantic on                 # 打开，用默认模型 qwen2.5:7b-instruct
loongagent local semantic on qwen2.5:0.6b    # 打开，自己选摘要模型
loongagent local semantic                    # 查看：开/关、模型、是否已 pull
loongagent local semantic on --record        # 只做确定性摘要，完全不调模型
loongagent local semantic off                # 关闭，已有的记忆保留
开好后不用管：归纳在后台空闲窗口里做，不占你打字的响应时间。 会话中按 F2 能看到记忆状态（record/semantic、各层条数、后台 worker）； 模型连不上时会自动退回 record 模式，状态栏显示 mem ⚠ degraded， 不会丢记忆、也不会卡住。

这几条命令只是替你编辑 ~/.loongagent/local.toml。手写配置长这样（受管部署时用）：

[context_engine]
enabled = true
mode    = "semantic"        # 关掉就写 "record"

[summarizer]
enabled  = true
kind     = "ollama"
base_url = "http://127.0.0.1:11434"
model    = "qwen2.5:7b-instruct"
摘要模型就是本机 ollama，对话内容不出机器；摘要存在 ~/.loongagent/ 下的派生库里，可以随时删掉重建（loong context rebuild）， 会话原文不受影响。目前只支持 ollama 作摘要后端。

6. （可选）装 VS Code 插件

文件夹里还有一个 .vsix 文件，是同一个 agent 的 VS Code 聊天面板：

code --install-extension loongagent-vscode-0.1.0.vsix

或者在 VS Code 里：扩展面板 → 右上角 ··· → Install from VSIX… 选中文件。 装好后点编辑器右上角的 loongagent 图标打开聊天面板。插件默认从 PATH 找二进制； 位置不一样就在设置里搜 loongagent.path 填上完整路径，或运行命令 loongagent: Locate the binary。

7. 常用速查

我想…敲这个
看看都配了什么模型loongagent local
删掉一个模型loongagent local delete 序号或名字
测一遍模型能不能通loongagent local ping
开/关语义记忆、看记忆状态loongagent local semantic on / off / 不带参数看状态
看每个设置最终生效的值loongagent config show
验证沙箱真的在生效loongagent sandbox self-test
列出所有历史会话 / 接着聊loongagent sessions / loongagent resume
在浏览器里用loongagent web（只监听本机）
所有配置和会话都在 ~/.loongagent/ 下（Windows 是 %USERPROFILE%\.loongagent\）。会话原文是 JSONL 日志，一行一个事件—— 这就是全部真相，删掉它记忆就没了。
