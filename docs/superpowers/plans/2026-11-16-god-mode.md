# God mode — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** a third permission mode, reachable only from inside a session
(`/god` in the TUI, a `GOD` button on the web page), that stops asking about
deletions and egress — the two things `/yolo` still asks about — and instead
refuses outright when a deletion reaches outside the workspace or when the
thing being sent is secret.

**Architecture:** one axis, three stops. `auto_approve: bool` becomes
`mode: PermissionMode` (`Ask` / `Yolo` / `God`) on the kernel, on the wire and
on both surfaces. `loong-tools` gains one pure function, `god_refusal`, that
looks at a shell command line and the workspace root and answers "refuse, and
why" or "nothing to refuse". The kernel calls it at the one place it already
decides whether an `Irreversible` ruling asks. Everything else — schema,
server, TUI, web — is wiring around those two.

**Tech Stack:** Rust workspace (`loong-schema`, `loong-tools`, `loong-kernel`,
`loong-server`, `loong-tui`, `loong-tui-app`, `loongagent`), the generated
protocol (`crates/schema/protocol.toml` → `scripts/gen-schema.py`), and the web
page (`crates/web/src/{index.html,app.js,style.css}`).

**Spec:** `docs/superpowers/specs/2026-11-16-god-mode-design.md`

## Global Constraints

- **God never relaxes a `Deny`.** It changes what a *question* becomes, never
  what a *prohibition* becomes. Sandbox refusals, hook tightenings and
  `Verdict::Deny` are untouched (spec §1).
- **`yolo` keeps its exact meaning.** ADR-0020 stays true for it. The only
  ruling that changes meaning is `God + Irreversible`.
- **No persistence, no flag, no config key.** God is reachable only through
  `permissions.set` / `/god` / the web button. `Kernel::create` and every
  resume start at `Ask`.
- **The gates communicate, they do not hide.** A refusal writes
  `policy.decided{verdict: deny}` plus a `tool.result` the model can read and
  act on, so a rewrite inside the gate still runs.
- **Module contracts** (`AGENTS.md`): every new `fn`, `struct` and `enum` gets a
  doc block — `Purpose:` plus the five labels, or `Purpose:` + `Contract:` for a
  private body of ≤ 12 lines. Types always carry the full block.
- **Length budgets**: `docs/design/tools-permissions.md` and
  `docs/design/surfaces.md` are at 250/250, `kernel-loop.md` and
  `web-surface.md` at 249/250. Every doc edit below must leave its file within
  budget by tightening the least-load-bearing restatement in the *same* file.
  Never delete a `Verify:` command, a link, or a `Code:` path to make room.
- Run tests with `XDG_RUNTIME_DIR=$TMPDIR` when the sandbox probes need it.
- `README.md` states the workspace test count (`<!-- test-counts: 2287 passed,
  21 ignored -->`); `scripts/check.sh` fails when it drifts. Update it in the
  last task from the run's own output, never by guessing.

## Review Focus

Judgement calls a reviewer should check rather than assume:

1. **The gate is a heuristic, and says so.** `god_refusal` reads a command
   line. Spec §4 lists what it cannot catch (a committed secret then pushed, a
   `python -c` that reads a keyfile). Do not let a later change describe it as a
   guarantee.
2. **Refuse, do not ask, when unsure.** An operand that cannot be resolved
   (`$X`, `*`, `~`) counts as outside. A false refusal costs one rewrite; a
   false allow costs the file.
3. **One decision in the log, not two.** The god refusal is decided *before*
   the first `policy.decided` is appended, so a replayed session shows
   `ask`→no, it shows exactly one `deny` with the gate's rule.
4. **`find` operands stop at the first predicate.** `find . -name '*.log'
   -delete` must be allowed while `find / -name '*.log' -delete` is refused;
   the `-name '*.log'` glob belongs to the predicate, not to the operand.
5. **Old logs replay.** `permissions.relaxed` gains `mode` as optional;
   absence means `auto_approve ? yolo : ask`.

  in an unattended run, and the answer is always yes. A question whose answer
  is always yes is not a decision. What protects the person is not the question
  but a refusal at the two places where a wrong answer is unrecoverable.
- **Decision §1:** a third mode, `god`, beside `ask` and `yolo`; reachable only

  configurable, on purpose.

```rust
/// How much autonomy a session has been granted, as one axis (ADR-0007 §5).
///
/// Three stops, not two: `Ask` is the default and the only one a session starts
/// in; `Yolo` turns every question into an allow but the irreversible one
/// (ADR-0020); `God` turns that one too, and refuses two shapes outright instead
/// of asking (ADR-0022).
///
/// Serves: `loong-kernel`'s dispatch, `loong-server`'s `permissions.set`,
/// `loong-tui`'s client and `loong-tui-app`'s screen.
/// Design: `docs/decisions/0022-god-mode-refuses-two-shapes.md`;
/// `docs/design/kernel-loop.md` §5.
/// Up: every crate that reads a `permissions.relaxed` event.
/// Down: nothing — a plain value.
/// Verify: `cargo test -p loong-schema`.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub enum PermissionMode {
    /// The default: a ruling that would ask parks for an answer.
    #[default]
    Ask,
    /// Every question becomes an allow but the irreversible one (ADR-0020).
    Yolo,
    /// That one too, minus the two shapes the gates refuse (ADR-0022).
    God,
}

impl PermissionMode {
    /// Purpose: The wire spelling, and the word the surfaces show.
    /// Contract: total; the three names are the schema's enum.
    pub fn as_str(self) -> &'static str {
        match self {
            PermissionMode::Ask => "ask",
            PermissionMode::Yolo => "yolo",
            PermissionMode::God => "god",
        }
    }

    /// Purpose: Read the wire spelling back, `None` for a word this build does not know.
    /// Contract: the inverse of `as_str`; never guesses.
    pub fn parse(text: &str) -> Option<Self> {
        match text {
            "ask" => Some(PermissionMode::Ask),
            "yolo" => Some(PermissionMode::Yolo),
            "god" => Some(PermissionMode::God),
            _ => None,
        }
    }

    /// Purpose: Whether a ruling that would ask is allowed instead.
    /// Contract: `false` only for `Ask`.
    pub fn skips_prompts(self) -> bool {
        !matches!(self, PermissionMode::Ask)
    }
}

impl std::str::FromStr for PermissionMode {
    type Err = String;

    /// Purpose: Parse the wire spelling, with the word in the message when it is wrong.
    /// Contract: `parse`, with an error rather than `None`.
    fn from_str(text: &str) -> Result<Self, Self::Err> {
        Self::parse(text).ok_or_else(|| format!("unknown permission mode {text:?}"))
    }
}

impl std::fmt::Display for PermissionMode {
    /// Purpose: Print the wire spelling.
    /// Contract: `as_str`.
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str(self.as_str())
    }
}
```

```rust
/// Purpose: The irreversible family one segment belongs to, or `None` when it is not irreversible.
/// Serves: `segment_irreversible_reason` and `god_refusal`.
/// Design: `docs/design/tools-permissions.md` §2; ADR-0020 §4.
/// Up: `segment_irreversible_reason`, `god_refusal`.
/// Down: `after_prefix`, `basename`, `carries_a_payload` and the three verb lists.
/// Verify: `cargo test -p loong-tools`.
fn segment_family(tokens: &[&str]) -> Option<IrreversibleFamily> {
    let i = after_prefix(tokens);
    let head = tokens.get(i)?;
    let verb = basename(head);
    let next = tokens.get(i + 1).map(|t| t.to_lowercase()).unwrap_or_default();
    let deletes = DELETE_VERBS.contains(&verb.as_str())
        || (verb == "git" && next == "rm")
        || (verb == "dd" && tokens.iter().any(|t| t.starts_with("of=")))
        || tokens.iter().any(|t| *t == "-delete");
    if deletes {
        return Some(IrreversibleFamily::Delete);
    }
    let egresses = EGRESS_VERBS.contains(&verb.as_str())
        || (verb == "git" && next == "push")
        || (matches!(verb.as_str(), "npm" | "pnpm" | "yarn") && next == "publish")
        || (verb == "cargo" && next == "publish")
        || (verb == "gh" && next == "release")
        || (matches!(verb.as_str(), "curl" | "wget") && carries_a_payload(&tokens[i + 1..]));
    if egresses {
        return Some(IrreversibleFamily::Egress);
    }
    None
}
```

```rust
/// Purpose: The index of the token that names the command, skipping `sudo`-style
/// prefixes and leading `NAME=value` assignments.
/// Contract: `tokens.len()` when every token is a prefix; callers use `get`.
fn after_prefix(tokens: &[&str]) -> usize {
    let mut i = 0;
    while i < tokens.len() {
        let word = tokens[i].to_lowercase();
        let assignment = tokens[i].contains('=') && !tokens[i].starts_with('-');
        if !PREFIX_WORDS.contains(&word.as_str()) && !assignment {
            break;
        }
        i += 1;
    }
    i
}
```

```rust
///
/// Serves: `GodRefusal` and the kernel's `policy.decided` rule.

pub enum GodGate {

    DeleteOutsideWorkspace,
    /// Egress of secret material: a keyfile, a credential store, or a `*_KEY` variable.
    SecretEgress,
}

impl GodGate {

    /// Contract: stable text; the log's meaning depends on it.
    pub fn rule(self) -> &'static str {

            GodGate::SecretEgress => "god:deny:secret-egress",

/// Why god mode would refuse this shell command, or `None` when it has nothing to refuse.
///
/// God allows every irreversible action the classifier finds — deleting, pushing,
/// publishing, uploading — except the two shapes whose consequence cannot be
/// undone and whose usual cause is a mistake (ADR-0022 §2, §3).
///
/// Purpose: The gate god mode keeps in place of the approval prompt.
/// Serves: `loong_kernel`'s `dispatch`, in the `Irreversible` arm.
/// Design: `docs/decisions/0022-god-mode-refuses-two-shapes.md`.
/// Up: `crates/kernel/src/turn/loop.rs`.
/// Down: `segments`, `segment_family`, `delete_operands`, `secret_marker`,
/// `resolve`.
/// Verify: `cargo test -p loong-tools god_`.
pub fn god_refusal(command: &str, cwd: &Path) -> Option<GodRefusal> {
    let segments = segments(command);
    for tokens in &segments {
        if segment_family(tokens) == Some(IrreversibleFamily::Delete) {
            if let Some(detail) = delete_gate(tokens, cwd) {
                return Some(GodRefusal {
                    gate: GodGate::DeleteOutsideWorkspace,
                    detail,
                });
            }
        }
    }
    let sends = segments
        .iter()
        .any(|t| segment_family(t) == Some(IrreversibleFamily::Egress));
    if sends {
        if let Some(marker) = segments.iter().find_map(|t| secret_marker(t)) {
            return Some(GodRefusal {
                gate: GodGate::SecretEgress,
                detail: format!("`{marker}` is secret material and this command sends data out"),
            });
        }
    }
    None
}

/// Purpose: Why a delete-family segment must be refused, or `None` when every operand is inside the workspace.
/// Serves: `god_refusal`.
/// Design: ADR-0022 §2; `docs/design/flows/tool-approval.md` §3.
/// Up: `god_refusal`.
/// Down: `after_prefix`, `delete_operands`, `expands_at_run_time`, `resolve`.
/// Verify: `cargo test -p loong-tools god_refuses_`.
fn delete_gate(tokens: &[&str], cwd: &Path) -> Option<String> {
    let operands = delete_operands(tokens);
    if operands.is_empty() {
        return Some("no path to resolve, so where it would delete is unknown".to_string());
    }
    let root = resolve(cwd, ".");
    for operand in operands {
        if expands_at_run_time(&operand) {
            return Some(format!(
                "`{operand}` is decided at run time, so it is treated as outside the workspace"
            ));
        }
        if !resolve(cwd, &operand).starts_with(&root) {
            return Some(format!("`{operand}` resolves outside the workspace"));
        }
    }
    None
}

/// Purpose: The paths a delete-family segment acts on.
/// Serves: `delete_gate`.
/// Design: ADR-0022 §2.
/// Up: `delete_gate`.
/// Down: `after_prefix`, `basename`, `unquote`.
/// Verify: `cargo test -p loong-tools god_`.
fn delete_operands(tokens: &[&str]) -> Vec<String> {
    let i = after_prefix(tokens);
    let Some(head) = tokens.get(i) else {
        return Vec::new();
    };
    let verb = basename(head);
    let next = tokens.get(i + 1).map(|t| t.to_lowercase()).unwrap_or_default();
    let operands: Vec<String> = if verb == "dd" {
        tokens
            .iter()
            .filter_map(|t| t.strip_prefix("of="))
            .map(unquote)
            .collect()
    } else if verb == "find" {
        // The paths are what `find` starts from; everything after the first
        // predicate flag is a test, and its `'*.log'` is not an operand.
        tokens[i + 1..]
            .iter()
            .take_while(|t| !t.starts_with('-'))
            .map(|t| unquote(t))
            .collect()
    } else {
        let from = if verb == "git" && next == "rm" { i + 2 } else { i + 1 };
        tokens[from..]
            .iter()
            .filter(|t| !t.starts_with('-'))
            .map(|t| unquote(t))
            .collect()
    };
    operands.into_iter().filter(|t| !t.is_empty()).collect()
}

/// Purpose: Whether a shell will decide this operand's value, so the gate cannot.
/// Contract: `$`, `*`, `?`, `[`, `{`, `` ` `` and a leading `~` all mean yes.
fn expands_at_run_time(operand: &str) -> bool {
    operand.starts_with('~') || operand.contains(['$', '*', '?', '[', '{', '`'])
}

/// Purpose: A path token without the quotes a shell would have stripped.
/// Contract: trims `"'``()``;` from both ends.
fn unquote(token: &str) -> String {
    token
        .trim_matches(|c: char| "\"'`();".contains(c))
        .to_string()
}

/// Purpose: The secret material named anywhere in a segment, as the text that names it.
/// Serves: `god_refusal`'s egress gate.
/// Design: ADR-0022 §3.
/// Up: `god_refusal`.
/// Down: `SECRET_FILES`, `SECRET_DIRS`, `is_secret_variable`.
/// Verify: `cargo test -p loong-tools god_refuses_egress_of_secret_material`.
fn secret_marker(tokens: &[&str]) -> Option<String> {
    for raw in tokens {
        let token = raw
            .trim_matches(|c: char| "\"'`();,".contains(c))
            .to_lowercase();
        if token.is_empty() {
            continue;
        }
        if let Some(variable) = token.strip_prefix('$') {
            let name = variable.trim_start_matches('{').trim_end_matches('}');
            if is_secret_variable(name) {
                return Some(format!("${name}"));
            }
            continue;
        }
        if matches!(token.as_str(), "env" | "printenv" | "export") {
            return Some(token);
        }
        let name = token.rsplit(['/', '\\']).next().unwrap_or(&token);
        if name.starts_with(".env") || SECRET_FILES.contains(&name) {
            return Some(name.to_string());
        }
        if SECRET_DIRS.iter().any(|dir| token.contains(dir)) {
            return Some(name.to_string());
        }
    }
    None
}

/// Purpose: Whether a variable's name says its value is a credential.
/// Contract: `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, `PASSWD`, `CREDENTIAL`, `AUTH`, case-insensitive.
fn is_secret_variable(name: &str) -> bool {
    let upper = name.to_uppercase();
    ["KEY", "TOKEN", "SECRET", "PASSWORD", "PASSWD", "CREDENTIAL", "AUTH"]
        .iter()
        .any(|needle| upper.contains(needle))
}
```

## Seen and not built (say no out loud)

- **A pre-push secret scan.** A committed secret then pushed is not caught by
  §3's gate, by construction (spec §4). Different feature.
- **Scrubbing config-loaded secrets from every child's environment.** It would
  break `curl -H "Authorization: $KEY"` and `cargo publish` with a registry
  token, and it changes every mode, not just god (spec §5). A per-command
  pass-through allowlist is its own spec.
- **Extra writable directories outside the workspace.** God does not widen the
  sandbox; a write to `/tmp/x` still asks, and still can be denied (spec §5).
- **A `--dangerously-skip-permissions` flag or a config key.** The person chose
  session-only; a persisted god is a god nobody remembers granting.
