# Archive — superseded history

Everything in this directory is **history, not current guidance**: the framing, the
trade-offs and the discussion the architecture was decided through. It is kept
because that reasoning cannot be recovered from a commit message. Nothing here is
maintained, and an archived file keeps the `Status:` / `Last updated:` headers it
had when it was archived — they are part of the record, not a claim about today.

| Archived | What it holds |
|---|---|
| [01-landscape-synthesis.md](01-landscape-synthesis.md) | The cross-tool synthesis, the T1–T10 design tensions, the round-2 landscape additions |
| [03-architecture-history.md](03-architecture-history.md) | `03`'s Part 1 (the pre-AQ historical framing) and Part 3 (the discussion log) |

## What supersedes what

- **[05-parity-and-synthesis.md](../05-parity-and-synthesis.md) supersedes `01`** —
  `05` is the current synthesis and the owner of the deliberate "no"s.
- **The ADRs supersede `03` Part 2.** The AQ-1…AQ-12 decision map is still live in
  [03-architecture.md](../03-architecture.md) as the question-by-question record;
  each ADR in [`decisions/`](../decisions/) is the authority for its answer.
- **Nothing supersedes the discussion log** — it is the record of the conversation,
  not a statement of the design.

[The docs index](../README.md) lists every current document.
