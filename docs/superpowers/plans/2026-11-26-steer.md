# Steer — implementation plan

> **For agentic workers:** implement task by task, in order. Each task names the
> files, the contract lines to update, and the test that proves it. `./scripts/check.sh`
> must be green at the end; test-first per task.

**Date:** 2026-11-26 · **Spec:** [specs/2026-11-26-steer-design.md](../specs/2026-11-26-steer-design.md) · **Status:** Proposed

The spec owns *why*. This plan owns *where* and *in what order*, and it is ordered
so that each layer is provable before the next one is wired to it.

## Task 1 — Documents first

Nothing changes behaviour until the owning documents say what the behaviour is.

- `docs/design/sessions-lineage.md` §5: the **Steer** row stops saying "not
  implemented"; the paragraph under the table says queue vs steer, exactly-once
  delivery, and the boundary rule. The same section's retry paragraph keeps its
  claim (`Alt+R` refuses while a turn runs) — steering does not change retry.
- `docs/design/kernel-loop.md` §5: the `/yolo` paragraph gains the steer point of
  application next to `apply_requested_permissions`, including "after the stop and
  stall checks, so a stop wins", and the hook gate.
- `docs/design/surfaces.md` §3: "enter during a turn refuses a new prompt" becomes
  the queue; the control-channel paragraph gains `steer "<json>"`; the
  `Ctrl-C`-clears-the-queue rule and the Windows degradation are named.
- `docs/decisions/0023-steer-rides-the-control-channel.md`: the new ADR, because
  ADR-0019 §1 said a second mid-turn intent needs one; `docs/README.md`'s index row gains
  it, and the three design docs link it.
- Verify: `python3 scripts/check-docs.py` (links, headers, budgets).

## Task 2 — Kernel: the slot and the boundary

- `crates/kernel/src/turn.rs`: `pub type SteerQueue = Arc<Mutex<VecDeque<String>>>`
  beside the permission slot; `Kernel.steer_request`; `steer_requestor()` and
  `use_steer_requester()` mirroring the permission pair.
- `crates/kernel/src/turn/loop.rs`: `Kernel::apply_requested_steer(&mut self, events)`
  drains the queue, fires `user_prompt_submit` per text, records the user message,
  and drops a text a tightening verdict refuses (assistant note in its place).
- `crates/kernel/src/turn/loop.rs` `run_inner`: call it after the interrupted and
  stall checks, before the model call.
- `crates/kernel/src/turn/loop.rs` `submit_with`: call it before `record_user(&prompt)`
  so a steer that missed its turn is spoken before the new prompt.
- Tests: a steer written during a model call reaches the next request (mirror
  `a_permissions_request_during_a_model_call_still_allows_the_call`); a steer
  written between turns precedes the next prompt; a tightening hook drops it.
- Verify: `cargo test -p loong-kernel`.

## Task 3 — Server: the control channel carries it

- `crates/server/src/lib.rs`: the control struct holds both slots; the reader
  thread splits `mode <word>` from `steer "<json>"`; `session.new` hands the slot
  to the new kernel with `use_steer_requester`.
- Test: a `steer` line written to the channel leaves the text in the kernel's slot,
  and a malformed one is ignored rather than killing the reader.
- Verify: `cargo test -p loong-server`.

## Task 4 — CLI: the write end

- `crates/cli/src/tui.rs`: one closure on the write end formats both lines;
  `spawn` returns it as the screen's `Control`.
- Test: `ask_steer("hi")` writes `steer "hi"` and escapes a newline.
- Verify: `cargo test -p loongagent`.

## Task 5 — The screen: queue, steer, flush

- `crates/tui-app/src/lib.rs`: `App.queue`, `App.steer`, `Action`/`begin_submit`
  reuse; `enter` while busy queues instead of refusing; `alt+enter` steers;
  `Ctrl-C` while busy clears the queue; `flush_queue()` sends the head when the
  turn ends and nothing is pending; hint bar shows `待发 N`.
- `crates/tui-app/src/commands.rs` + `surface_command`: `/steer <text>` as the typed
  fallback.
- `crates/tui-app/src/surface.rs`: take one `Control` instead of the permission
  closure, call `flush_queue` after every drain.
- Tests: busy `enter` queues; `alt+enter` calls the steer closure with the input
  text and with the queue head; the flush sends the head only when idle and never
  while an approval is pending; `Ctrl-C` clears; `/steer` routes.
- Verify: `cargo test -p loong-tui-app`.

## Task 6 — The gates

- `cargo fmt --all`, `python3 scripts/check-modules.py`, `python3 scripts/check-docs.py`,
  `./scripts/check.sh`. Every new `fn`, field and type carries its contract block;
  every edited document stays inside its class budget.
